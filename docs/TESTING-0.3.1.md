# 0.3.1 手测清单（全文搜索 + 简繁转换）

> 版本：**0.3.1**　平台：Windows x64 / Android arm64
> 这一版同时包含上一批「阅读交互」改动（工具栏 / 滑动翻页 / 单栏宽屏），所以最后有一组回归项。
> 测试时建议用**一本你熟悉的书**，并准备**一本繁体书**（测「繁→简」）。
>
> 发现问题时请按最后「报问题模板」发我：书名 + 步骤 + 期望 + 实际 + 截图。

---

## 一、安装与升级

- [ ] **Windows**：装 `Inkwell-0.3.1-win-x64-setup.exe`，能正常启动，书库和原有进度都在
- [ ] **Android**：装 `Inkwell-0.3.1-arm64.apk`（未装过旧版就直接装；装过旧版应能覆盖安装）
- [ ] 打开「设置」类页面，关于/日志里版本应为 **0.3.1**
- [ ] 原有书籍、书签、批注、阅读进度都还在

---

## 二、单本全文搜索

### T1 打开搜索面板

- [ ] 进入阅读器，顶栏有「搜索」按钮
- [ ] 点「搜索」→ 右侧出现「全文搜索」面板，输入框自动获得焦点
- [ ] 再点一次「搜索」（或点面板右上角 ✕）→ 面板关闭

### T2 基本搜索

- [ ] 输入一个书中确定存在的词（如「毛泽东」），按回车或点「搜索」
- [ ] 搜索过程中显示「正在搜索… N%」，有进度条
- [ ] 完成后显示「共 N 处」「M 个章节」，结果按章节分组
- [ ] 每条结果显示命中词前后文，命中词有底色高亮

### T3 结果分页

- [ ] 搜一个常见词，结果很多时，列表顶部显示「已显示 200」
- [ ] 列表底部有「显示更多（还有 N 处）」
- [ ] 点一次变成 400 条，再点继续增加
- [ ] 滚动长列表不卡死（这是这次特意限制 200 条的原因）

### T4 点击跳转

- [ ] 点任意一条结果 → 正文跳到对应位置
- [ ] 搜索面板**保持打开**，方便继续点下一条
- [ ] 正文里能看到搜索命中的描边（outline）
- [ ] 关闭面板后，描边消失

### T5 无结果 / 特殊输入

- [ ] 输入书中不存在的词 → 显示「没有找到「…」」
- [ ] 空输入时「搜索」按钮不可点
- [ ] 搜索中再按回车不会重复发起（按钮显示「搜索中…」并禁用）
- [ ] 搜索中关闭面板 → 不再往列表里追加结果

### T6 PDF / 固定版式

- [ ] 打开一本 PDF（或漫画）→ 顶栏**不显示**「搜索」按钮（没有文本层，避免能点但没结果）

### T7 跨章节

- [ ] 搜一个在多章都出现的词 → 结果分组涵盖多个章节，点不同章节的结果都能跳对

## 三、简繁转换

> 「繁→简」需要一本繁体书；「简→繁」用任意简体书即可。
> 如果手头没有繁体书，先只测「简→繁」，再找一本繁体书补测「繁→简」。

### T8 设置项

- [ ] 阅读设置面板里有「简繁转换」一行
- [ ] 三个选项：**关 / 繁→简 / 简→繁**
- [ ] 默认是「关」

### T9 简→繁

- [ ] 打开一本简体书，选「简→繁」
- [ ] 正文变成繁体（如「毛泽东」→「毛澤東」、「图书」→「圖書」）
- [ ] 页码 / 进度百分比**没有跳变**（允许因分页重算有 1 页内的变化，但不能跳到全书别处）
- [ ] 翻几页，后续章节也保持繁体
- [ ] 切到「关」→ 正文逐字恢复简体

### T10 繁→简

- [ ] 打开一本繁体书，选「繁→简」
- [ ] 正文变成简体（如「漢語」→「汉语」、「這是一個測試」→「这是一个测试」）
- [ ] 切回「关」→ 恢复繁体原文

### T11 重启记忆

- [ ] 选「简→繁」后彻底退出应用，重新打开同一本书
- [ ] 设置仍是「简→繁」，正文仍是繁体

### T12 转换 + 批注 / 书签

- [ ] 在「简→繁」状态下划词加一条高亮
- [ ] 切回「关」，高亮仍在原来的文字上，没有错位
- [ ] 再切回「简→繁」，高亮仍在
- [ ] 加一个书签，切换转换方向，书签仍能跳回同一页

### T13 转换 + 搜索

- [ ] 在「简→繁」状态下，用**简体**关键词搜索（如「出乡关」）
- [ ] 能搜到结果，摘录显示为繁体（「出鄉關」）
- [ ] 在「繁→简」状态下，用**繁体**关键词搜索，能搜到简体原文
- [ ] 搜索结果的点击跳转正常

### T14 滚动模式

- [ ] 切到「滚动」翻页方式，再切「简→繁 / 繁→简」
- [ ] 正文转换正常，滚动位置不跳到书首

### T15 PDF

- [ ] PDF 下切「简→繁」不应报错（PDF 是位图，文字不会变，这是预期）

## 四、上一批改动的回归（0.3.1 也包含）

### T16 移动端工具栏

- [ ] 阅读时点右侧/左侧翻页区 → 翻页，**工具栏不出现**
- [ ] 横向滑动翻页 → 工具栏不出现
- [ ] 双击正文中间 → 工具栏出现；再双击 → 隐藏
- [ ] 点顶部/底部空白区 → 工具栏不出现

### T17 滑动翻页

- [ ] 慢慢横向拖约 20% 屏宽后松手 → 翻到下一页（或上一页），不再弹回
- [ ] 只拖 10% 左右 → 不翻页，回弹
- [ ] 快速轻扫 → 仍能翻页
- [ ] 下拉书签手势仍然可用，不与横滑打架

### T18 单栏宽屏（桌面）

- [ ] 设置 → 单栏下出现「单栏宽度：标准 / 宽屏」
- [ ] 选「宽屏」→ 正文明显变宽、铺满窗口，两侧仍留一点空白
- [ ] 切「双栏」→ 宽屏选项隐藏，双栏排版正常
- [ ] 切回单栏 → 宽屏选择仍生效
- [ ] 重启应用后宽屏选择仍在

## 五、报问题模板

请按这个格式发我，方便一次定位：

```
版本：0.3.1 / Windows 或 Android
书名：
步骤：
  1.
  2.
期望：
实际：
截图/录屏：
是否必现：
```

优先关注：

1. 搜索能不能出结果、点击是否跳对、长列表是否卡；
2. 简繁转换有没有漏字、错字、页码乱跳；
3. 转换后书签/批注是否错位；
4. Android 上搜索面板是否被输入法遮挡、侧栏是否过宽。

> 已知限制（不是 bug，先说明）：
> - 简繁转换目前是**全局**设置，不是按书设置；
> - 为保 CFI，极少数会导致 UTF-16 长度变化的字符会保留原文；
> - 大书搜常见词需要等，关闭面板可取消；
> - PDF / 漫画不支持搜索和简繁转换。
