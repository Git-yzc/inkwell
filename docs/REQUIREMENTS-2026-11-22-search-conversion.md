## 二、全文搜索

### 实现

- **入口**：阅读页顶栏「搜索」。PDF / 固定版式不显示（内核没有可搜索的文本层）。
- **面板**：右侧 320px 侧栏，输入关键词后**回车或点「搜索」**（有意不做输入即搜：
  全书搜索要逐章加载文档，边打边搜会把主线程拖住）。
- **结果**：按章节分组，显示命中前后各 50 字，命中词高亮；顶部显示「共 N 处 / M 个章节」。
- **分页渲染**：一次只渲染前 200 条，底部「显示更多」每次 +200。实测《毛泽东传》
  搜「毛泽东」命中 **12104 处 / 94 章**，如果全渲染会挂上万个 DOM 节点。
- **跳转**：点结果调 `engine.goTo(cfi)`，面板保持打开，方便连续查看。
- **描边**：内核 `view.search()` 会在正文里给所有命中画 outline；关闭面板 /
  切换其他侧栏时 `engine.clearSearch()` 清掉。
- **取消**：引擎用 `#searchToken` 让旧的异步循环在关闭 / 新搜索时停下，
  避免旧结果继续往列表里追加。
- **简繁联动**：转换开启时，用户输入会先转到**原文那一侧**再搜索（否则简繁互搜搜不到），
  章节名与摘录再转成当前显示文字。

### 关键实现位置

| 位置 | 作用 |
| --- | --- |
| `src/features/reader/SearchPanel.tsx` | 搜索侧栏、结果列表、200 条分页 |
| `engine/index.ts` 的 `search()` / `clearSearch()` | 包一层 `view.search()`，处理简繁、取消、事件映射 |
| `engine/types.ts` 的 `SearchEvent` / `SearchHit` | 稳定的对外接口 |
| `foliate-js.d.ts` | 声明 `view.search()` / `clearSearch()` |

## 三、简繁转换

### 实现

- 依赖 **opencc-js 1.4.2**（MIT AND Apache-2.0，纯 JS，字典打包进产物，不联网）。
- 设置面板新增「简繁转换」：**关 / 繁→简 / 简→繁**，全局生效，存 localStorage。
- 转换发生在**渲染后的书籍 DOM 文本节点**上，不改原书文件、不改数据库：
  - 内核换章节会重建文档，`load` 事件里重新转换；
  - 切设置时用「原文备份」重新转换 / 还原；
  - 搜索面板的章节名与摘录也走同一个转换器。
- **CFI 安全**：OpenCC 通用繁简字典逐条**码点等长**（实测 TSPhrases / STPhrases /
  TSCharacters / STCharacters 的码点长度差异为 0）；极少数兼容表意文字会因代理对在
  UTF-16 上差 1 个 code unit。转换时按文本节点校验 UTF-16 长度，**长度变了就保留原文**，
  宁可少转一句也不让书签 / 批注的 CFI 错位。
- 固定版式（PDF / 漫画）跳过：整页位图没有可转换的文字层。

### 关键实现位置

| 位置 | 作用 |
| --- | --- |
| `src/features/reader/engine/conversion.ts` | opencc 转换器、DOM 遍历、长度保护、原文还原 |
| `src/features/reader/SettingsPanel.tsx` | 「繁→简 / 简→繁 / 关」按钮 |
| `engine/index.ts` 的 `#applyConversion()` | 换章 / 切设置时调用，并在文字变化后重新分页 |
| `engine/types.ts` 的 `ConversionMode` | 设置与搜索共用的方向类型 |

## 四、决策

| 编号 | 决策 | 理由 |
| --- | --- | --- |
| S1 | 搜索用**显式提交**，不做输入即搜 | 全书搜索逐章加载，边打边搜会卡 |
| S2 | 结果一次渲染 200 条，可「显示更多」 | 常见词可命中上万条，全渲染会卡 |
| S3 | 搜索面板保持打开，点结果只跳转 | 方便连续查看多条命中 |
| S4 | PDF / 固定版式不显示搜索入口 | 没有文本层，避免「能点但没结果」 |
| C1 | 只做**全局**简繁开关，暂不做按书设置 | 需求未明确要求按书；按书需要额外的存储与 UI |
| C2 | 两个方向都做（繁→简 / 简→繁） | 需求是「简繁转换」，只做一个方向不完整 |
| C3 | 转换只改 DOM，不改原书 / 数据库 | 保持 CFI 与批注数据不变 |
| C4 | 文本节点长度变化时保留原文 | 宁可局部不转，也不破坏 CFI |
| C5 | opencc-js 静态打包进主 bundle | 实现简单；代价是主包 +约 1.2 MB（gzip 约 0.4 MB） |

## 六、已知限制

| 项 | 说明 |
| --- | --- |
| Android 真机未验 | 搜索侧栏宽度、输入法弹出、长列表滚动都需要真机确认 |
| 按书设置未做 | 目前是全局开关；同一本书切走再回来仍沿用全局值 |
| 大书搜索耗时 | 逐章加载，几十 MB 的书搜常见词要等；目前只有进度条，没有「停止」按钮（关闭面板可取消） |
| 主 bundle 变大 | opencc-js 让 index 从约 410 KB 涨到约 1.61 MB（gzip 约 648 KB）；若不能接受，下一步改成 dynamic import + 首次使用时加载 |
| 极少数字符不转 | 为保 CFI，文本节点 UTF-16 长度变化时整节点保留原文 |
| 搜索描边 | 关闭面板即清除；这是有意的，不在正文里留常驻高亮 |
